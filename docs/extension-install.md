# Install the NexiFlow Chrome Extension (Office / Enterprise Customers)

If your plan includes **Office/Enterprise** features, NexiFlow uses a Chrome extension to enable time tracking features like optional screenshot capture (when enabled).

> Important: For security reasons, Chrome does **not** allow websites (including NexiFlow) to silently install extensions. You’ll be redirected to the Chrome Web Store to install it yourself.

## What you’ll be redirected to

You’ll be redirected to our **Unlisted** Chrome Web Store page.

- Unlisted means: it won’t show up in Chrome Web Store search results, but anyone with the link can install it.
- Install link: **REPLACE_ME_WITH_WEB_STORE_UNLISTED_LINK**
  - Example format: `https://chrome.google.com/webstore/detail/<extension-id>`

## Requirements

- Google Chrome (or a Chromium-based browser that supports Chrome Web Store installs)
- Permission to install extensions on your device
  - If you’re on a managed work device, your IT admin may need to allow extension installs.

## How to install (step-by-step)

1. Open the Chrome Web Store link above in **Chrome**.
2. Click **Add to Chrome**.
3. Confirm the installation when Chrome asks.
4. (Optional) Pin it:
   - Click the Extensions icon (puzzle piece) in Chrome
   - Pin **NexiFlow Time Tracker**
5. Go back to NexiFlow and refresh the page.
6. Open the extension and sign in with your NexiFlow account.

## How it works (high level)

- You start a timer inside the extension.
- NexiFlow records time entries based on the client/project/description you select.
- If you enable screenshots, the extension can capture and upload screenshots on a schedule while tracking is active.
  - If you do **not** grant screen permission, screenshots will capture the **active tab only**.

## Privacy & controls

- Screenshots are **optional** and controlled by a toggle in the extension.
- You can stop tracking at any time.
- You can log out from the extension at any time.

## Troubleshooting

### “Add to Chrome” is missing or blocked

- Your browser might not support Chrome Web Store installs.
- Your device may be managed by an organization that restricts extension installation.
  - Contact your IT admin and ask them to allow the NexiFlow extension.

### The extension installed, but nothing happens in NexiFlow

- Refresh the NexiFlow page.
- Make sure you’re logged into the extension.
- Make sure you’re using the same NexiFlow account you use in the web app.

### Screenshot permission prompt doesn’t appear

- Screenshot permission is optional; the extension can still function without it.
- Check Chrome Settings → Privacy and security → Site settings, and confirm screen capture permissions if your environment manages them.
